# Prise en main

Découvrez comment utiliser le logiciel :

* [Activation et licences](../getting-started/activation-and-licenses/activation-and-licenses.md) : cette page contient des informations sur l’activation et la gestion de vos licences afin que vous puissiez commencer à utiliser Designer.
* [Configuration requise](../getting-started/system-requirements/system-requirements.md) : cette page répertorie la configuration requise et les informations de compatibilité matérielle.
* [Vue d’ensemble](../getting-started/overview/overview.md) : cette page présente Substance 3D Designer (voir aussi https://www.adobe.com/fr/products/substance3d-designer.html), une comparaison avec d’autres applications de l’écosystème de Substance, et le type de fichiers et de ressources avec lesquels vous allez travailler.
* [Vue d’ensemble du workflow](../getting-started/workflow-overview/workflow-overview.md) : cette page explique le concept des workflows basés sur les nœuds et fournit un résumé des 3 principaux types de graphes que vous pouvez créer dans Designer.
* [Raccourcis](../getting-started/shortcuts/shortcuts.md) : cette page vous donne un aperçu de tous les raccourcis de Substance 3D Designer.
* [Tutoriels et apprentissage](../getting-started/tutorials-learning/tutorials-learning.md) : si vous préférez vous aider de vidéos et autres supports d’apprentissage plus ciblés, ces tutoriels sont parfaits pour commencer.
