# Script

Il est possible de contrôler l&#39;application en écrivant des plug-ins. Les plug-ins peuvent être écrits dans le langage de script **Python** à l&#39;aide de la version **3.9**. L’API Python fournie dans l’application permet d’accéder à de nombreuses fonctionnalités et de les utiliser directement à partir de scripts.

[Python](https://www.python.org/) est un langage de script largement utilisé dans de nombreux secteurs d&#39;activité. Il aide à créer des outils d’automatisation, d’accélération du workflow et de gestion des actifs, entre autres. La documentation de l’API est accessible à partir du menu principal avec l’action **Aide** > **Documentation sur les scripts...**.
