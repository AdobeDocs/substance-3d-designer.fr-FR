# Modules externes

Les packages Python sont pris en charge pour créer des plug-ins afin d’étendre l’application.

Ce sont des fichiers uniques avec une extension sdplugin contenant tout ce dont un plug-in a besoin pour fonctionner. Pour les développeurs, les packs simplifient le partage et la distribution de plug-ins aux utilisateurs. Pour les utilisateurs, les packs sont plus faciles à installer et à gérer.

## Installation de packs de plug-ins

![Gestionnaire de plug-ins](plugins-packages.resources/screenshot-from-2019-07-18-11-48-56.png "Gestionnaire de plug-ins")

Les packages de plug-ins sont installés à l&#39;aide de <b>Plugin Manager</b>, dans le menu <b>Outils</b> :

1. Cliquez sur le bouton <b>Installer</b> et sélectionnez le pack de plug-ins à installer
1. Le plug-in sera installé dans le répertoire de base, dans le chemin par défaut pour les plug-ins de chaque système d’exploitation
1. Une fois le plug-in installé, il sera automatiquement chargé
