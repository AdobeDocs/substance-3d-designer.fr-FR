# Éditeur Python

Substance 3D Designer comprend un **éditeur de script**, qui permet aux utilisateurs de **tester le code Python** directement dans Designer et d&#39;obtenir sa **sortie console**.

![Éditeur Python](python-editor.resources/python-editor-01.png "Éditeur Python")

L&#39;éditeur dispose d&#39;une fonctionnalité « **Rechercher et remplacer** », accessible dans l&#39;élément « *Modifier > Rechercher...* » de la barre de menus de l&#39;éditeur ou en appuyant sur *Ctrl+F*.

![Rechercher et remplacer dans l’éditeur Python](python-editor.resources/python-editor-02.png "Rechercher et remplacer dans l’éditeur Python")

Dans l&#39;esprit du **test** **but** de l&#39;éditeur Python, les utilisateurs peuvent tester tout le code en appuyant sur le bouton « *Exécuter* » dans la barre d&#39;outils de l&#39;éditeur (ou en appuyant sur *F5*), ou sur la **sélection actuelle uniquement** en appuyant sur le bouton « *Exécuter la sélection* » (ou en appuyant sur « *Ctrl+Entrée* »).

![Exécuter le code sélectionné dans l&#39;éditeur Python](python-editor.resources/python-editor-03.png "Exécuter le code sélectionné dans l&#39;éditeur Python")
