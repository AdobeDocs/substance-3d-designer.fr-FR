# Version 2020.2 (10.2)

**Substance Designer 2020.2** apporte une nouvelle mise à jour des Substances Engine, un workflow amélioré pour exposer les paramètres, des améliorations de performances et un nouveau contenu.

Date de publication : *12 octobre 2020*

## Principales fonctionnalités

### Nouvelle mise à jour de Moteur (version 8)

![](version-2020-2-10-2.resources/banner-enginev8.jpg)

Dans cette nouvelle version, la Substance Engine est maintenant dans la version 8 et apporte de nouvelles fonctionnalités et plusieurs améliorations :

* **Valeurs par défaut pour les images d&#39;entrée**\
  Les entrées d’image dans graphe peuvent désormais définir une couleur par défaut, ce qui facilite l’utilisation d’une valeur appropriée lorsque rien n’est chargé ou connecté à cette entrée.

  ![](version-2020-2-10-2.resources/input-color-default.jpg){width="600px"}

* **Nouveaux modes de distance**\
  [Le nœud de distance](../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/distance/distance.md) a maintenant deux nouveaux modes qui changent la façon dont le calcul est effectué :

  * **Euclidienne** (mode d&#39;origine) : distance de ligne droite entre les points dans la géométrie euclidienne.
  * **Manhattan** : distance entre les points, mais contrainte sur une grille, similaire à un pâté de maisons.
  * **Tchebychev** : distance maximale par rapport à la différence de deux points sur une grille de taille uniforme.

  ![](version-2020-2-10-2.resources/distance-comparison.jpg){width="600px"}

* **Nouvelle interpolation de dégradé**&#x200B;[&#x200B; Le nœud de dégradé](../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/gradient-map/gradient-map.md) possède un nouveau mode **Lisse** pour interpoler les touches, ce qui produit des transitions de couleurs beaucoup plus naturelles. Il fonctionne en regardant les clés de voisinage. Le mode précédent **Interpolation** a été renommé en **Tangente plate**.

  ![](version-2020-2-10-2.resources/gradient-comparison.png){width="600px"}

  ![](version-2020-2-10-2.resources/gradient-dropdow.png)

  Il existe également un paramètre supplémentaire pour le mode **Lisse** qui contrôle la longueur de la Tangente utilisée pour calculer la courbe qui fusionne entre les couleurs. Une valeur de 0 signifie que les tangentes ont une longueur de 0, tandis qu’une valeur de 1 signifie que les tangentes seront divisées par deux.

  ![](version-2020-2-10-2.resources/gradient-smooth-param.png)

* **Nœud de courbe amélioré**&#x200B;[&#x200B; Le nœud de courbe](../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/curve/curve.md) peut désormais générer directement une image en niveaux de gris. Cette modification permet de définir une courbe et de l’exporter directement sans avoir à brancher au préalable une texture de dégradé.

  ![](version-2020-2-10-2.resources/curve-grayscale-output.png)

### Amélioration du paramètre d’expose

![](version-2020-2-10-2.resources/banner-exposeparam.png)

Le workflow pour exposer et modifier les paramètres a été amélioré pour être plus simple :

* **Les actions de menu améliorées** Les actions permettant d&#39;exposer aux paramètres exposés et de les modifier ont été séparées pour être plus explicites. Un nouveau raccourci a également été introduit pour modifier plus facilement et plus rapidement les paramètres exposés. Par exemple, il existe désormais un bouton dédié pour modifier la fonction d&#39;un paramètre et une action dédiée pour accéder au paramètre de graphe exposé.

  ![](version-2020-2-10-2.resources/param-edit.png)

  ![](version-2020-2-10-2.resources/param-expose.png)

* **Configuration directe du nouveau paramètre à partir de la boîte de dialogue** Lorsque vous exposez un paramètre, tous les contrôles réguliers tels que la description et les valeurs par défaut sont désormais accessibles à partir de la boîte de dialogue **Exposer le paramètre**. Cela facilite et accélère la configuration et la création de nouveaux paramètres de Graphe, évitant ainsi d&#39;avoir à accéder à la vue des paramètres de Graphe immédiatement après la création d&#39;un paramètre.

  ![](version-2020-2-10-2.resources/expose-param-window.png){width="600px"}

### Configuration d’icône améliorée pour le graphe de Substance

![](version-2020-2-10-2.resources/banner-thumbnail-generator.jpg)

La configuration des vignettes dans le graphe de Substance est désormais beaucoup plus facile grâce à l’interface améliorée :

* **Génération automatique de vignettes de graphe**\
  Il est désormais possible de générer automatiquement un aperçu d’un graphe de Substance en cliquant simplement sur le bouton Générer en regard de l’icône dans les paramètres du graphe. Actuellement, il prend uniquement en charge le graphe utilisant le workflow PBR Métallique/de Rugosité comme nœuds de sortie. Lors de la génération de la vignette, l’intensité du displacement est calculée à partir de la valeur de Taille physique si elle est définie. Sinon, elle prend par défaut la valeur 0,1.

  ![](version-2020-2-10-2.resources/sd-thumb-generation.gif){width="600px"}

* **Ajout de vignettes personnalisées avec les nouveaux boutons**\
  Nous avons ajouté plusieurs nouveaux boutons pour simplifier la configuration des vignettes personnalisées :

  * **Parcourir** : ouvrez une boîte de dialogue de fichier pour charger une image. Vous pouvez également cliquer sur l’icône de dossier en regard des boutons.
  * **Générer** : voir la démonstration ci-dessus.
  * **Coller** : chargez une image à partir du Presse-papiers.
  * **Supprimer** : supprimez l&#39;image actuellement affectée à l&#39;icône.

  ![](version-2020-2-10-2.resources/icon-graph-properties.png)

### Performances améliorées

![](version-2020-2-10-2.resources/banner-car-speed.jpg)

Deux nouvelles optimisations ont été effectuées dans cette nouvelle version pour réduire le temps entre les itérations :

* **Amélioration des performances du calcul de graphe**\
  Les nœuds de sortie sont maintenant directement calculés à la demande au lieu de calculer les nœuds intermédiaires en chemin (ce qui est maintenant dans une deuxième étape). Cette modification permet de prévisualiser les résultats d’un graphe beaucoup plus rapidement, même en modifiant les nœuds racine. Dans la comparaison ci-dessous, cette optimisation permet de voir plus d&#39;itérations du graphe dans la même période de temps (ici avec un matériau à une résolution 4K):

  ![](version-2020-2-10-2.resources/perf-graph.gif)

* **Amélioration de la dilatation et de la génération de diffusions Baker**\
  La génération de la dilatation et de la diffusion des textures bakées est désormais jusqu’à 4 fois plus rapide que dans les versions précédentes. Cela réduit le temps d&#39;attente entre les bakes.

  ![](version-2020-2-10-2.resources/perf-bakers-padding.gif)

### Nouveau contenu

![](version-2020-2-10-2.resources/banner-content-6.jpg)

Cette version inclut l’ajout de quelques nouveaux nœuds, ainsi que des possibilités supplémentaires sur certains nœuds existants :

* **[Nouveau filtre Seuil](../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/threshold/threshold.md)**&#x200B;ce nœud permet d&#39;isoler rapidement en tant que noir et masque blanc une partie d&#39;une image en fonction d&#39;une entrée en niveaux de gris. En pratique, ce filtre est similaire au filtre Histogramme Scan existant, mais il est plus pratique à utiliser au quotidien. Pour en savoir plus, consultez la [page de documentation dédiée](../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/threshold/threshold.md).

  ![](version-2020-2-10-2.resources/treshold.jpg){width="650px"}

* **[Nouveau filtre de section transversale](../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/cross-section/cross-section.md)**&#x200B;ce nœud permet de visualiser la forme d&#39;une entrée en niveaux de gris en tant que profil, ce qui facilite considérablement la création de la carte de hauteur et des formes avec ce filtre en tant qu&#39;outil de débogage. Pour plus d&#39;informations, consultez la [page de documentation dédiée](../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/cross-section/cross-section.md).

  ![](version-2020-2-10-2.resources/profile-14.jpg){width="600px"}

  ![](version-2020-2-10-2.resources/cross-demo.jpg){width="600px"}

* **Amélioration du [Tile Generator](../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md) et du** [**Mosaïque Sampler**](../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-sampler/tile-sampler.md)\
  Ces deux nœuds disposent désormais de nouveaux paramètres pour développer d’autres capacités et utilisations :

  * **Conserver le rapport** : conservez le rapport des carreaux, vous n’avez pas besoin de compenser manuellement la taille lorsque le nombre sur l’axe X et Y est inégal.
  * **Absolue** : conservez au carreau un pourcentage prédéfini de la largeur de l’image finale.
  * **Pixel** : définissez la taille du carreau en pixels.

  Pour plus de détails, consultez la [page de documentation dédiée](../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md).

  ![](version-2020-2-10-2.resources/tile-generator-size-mode.gif)
