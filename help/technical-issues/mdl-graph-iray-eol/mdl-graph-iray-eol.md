# Les fonctionnalités de rendu graphique MDL et Iray sont manquantes

## Fin de vie

Les graphiques MDL et le rendu Iray ont été <b>supprimés</b> dans la version <b>16.0.0</b> de Substance 3D Designer.

Pour les rendus 3D photoréalistes, vous pouvez utiliser notre moteur de rendu par Pathtracer GPU. Ce moteur de rendu est développé en interne et sera progressivement déployé dans les applications Substance 3D.

En ce qui concerne la prise en charge de MDL, elle est en cours de suppression dans Substance 3D avec [MaterialX](https://materialx.org/) comme langue ombrage de choix pour les définitions de matériaux interchangeables et largement prises en charge.

La version <b>15.1.3</b> est la *dernière* version de Designer prenant en charge les graphiques MDL et le rendu Iray. Les utilisateurs de cette fonctionnalité ne doivent donc pas effectuer de mise à jour vers des versions supérieures.

La documentation de ces fonctionnalités est toujours disponible ici :

* [Graphiques MDL](../../mdl-graphs/mdl-graphs.md)
* [Iray](../../interface/3d-view/iray/iray.md)
