# La fonction de graphe de modèle de Substance est manquante

## Fin de vie

Les graphiques de modèles de Substance ont été notre première incursion dans la modélisation paramétrique et ont ensuite <b>été retirés</b> dans la version <b>13.0.0</b> de Substance 3D Designer.

La version <b>12.4.1</b> est la *dernière* version de Designer avec prise en charge des graphiques de Substance de données. Les utilisateurs de cette fonctionnalité ne doivent donc pas effectuer de mise à jour vers des versions supérieures.
