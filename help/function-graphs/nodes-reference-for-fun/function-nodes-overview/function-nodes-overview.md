# Présentation des noeuds de fonction

Cette page fournit un aperçu complet de tous les noeuds de fonction et explique le codage couleur utilisé pour les types de données de fonction. Vous pouvez cliquer sur des pages plus détaillées avec des explications supplémentaires.

Pour accéder à ces noeuds de fonction, cliquez avec le bouton droit de la souris dans l’éditeur de fonction de graphe et sélectionnez Elément, appuyez sur la barre d’espace ou la touche Tab dans une fonction ou accédez à la section Fonctions de la bibliothèque.
