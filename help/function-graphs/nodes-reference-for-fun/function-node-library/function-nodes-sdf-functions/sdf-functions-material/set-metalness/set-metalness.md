## Description

Définissez la métallisation du matériau d’une scène SDF.

Cette valeur peut ensuite être récupérée pour toutes les formes SDF éclaboussées dans la sortie *SDF metalness* de [Shape splatter v2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md).
