# Création et modification d’une fonction

## Création d’une fonction

Pour créer une fonction, il vous suffit de cliquer sur l&#39;icône de fonction ![](create-and-edit-a-function.resources/create-and-edit-a-function-01.png) et de choisir « **Fonction vide** ».

![](create-and-edit-a-function.resources/create-and-edit-a-function-02.png)

## Modification d’une fonction

Une fois qu’une fonction a été créée, vous pouvez la modifier en cliquant à nouveau sur l’icône de fonction ou en choisissant Modifier dans la liste déroulante.

![](create-and-edit-a-function.resources/create-and-edit-a-function-03.png)

Vous entrerez ensuite dans le mode de fonction du graphique.

## Graphique de fonction

Le graphique de fonction fonctionne de la même manière que les autres types de graphiques dans Designer : avec un éditeur de nœuds.

## Créer des nœuds

Vous pouvez créer des nœuds en cliquant avec le bouton droit de la souris dans le graphique et en choisissant « Ajouter un élément », ou en appuyant sur la barre d’espace :

![](create-and-edit-a-function.resources/create-and-edit-a-function-04.png){width="600px"}

## Définition d’une sortie

Contrairement au graphique de Substance, la fonction n&#39;a pas de nœud « Output », vous devez spécifier quel nœud dans le graphique est la sortie de la fonction.

Vous pouvez définir une sortie en cliquant avec le bouton droit de la souris sur un nœud et en choisissant <b>« Définir comme nœud de sortie ».</b>

Le nœud défini comme sortie devient jaune.

>[!NOTE]
>
> **Type de sortie**
> 
> Le nœud que vous souhaitez définir comme sortie doit contenir le même type de valeur que le paramètre qu&#39;il contrôle. Si ce n’est pas le cas, l’option « Définir comme nœud de sortie » sera grisée.

>[!WARNING]
>
> Une fonction doit avoir une sortie pour fonctionner. Un avertissement s’affiche dans votre graphique si aucune sortie n’est définie pour votre fonction.
