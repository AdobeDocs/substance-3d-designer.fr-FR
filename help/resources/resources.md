# Ressources

Les ressources correspondent au contenu des packs Substance 3D Designer. Ils sont utilisés pour créer, générer et prévisualiser des données de matériau et de texture. Les ressources peuvent être divisées en deux grandes catégories : les ressources de Graphe et les autres ressources. La méthode utilisée pour créer ou importer des ressources diffère selon les types. Pour mieux comprendre cela, consultez la page dédiée [Liaison, importation et nouvelles ressources](../resources/importing-linking-and-new/importing-linking-and-new-resources.md).

### RESSOURCES HORS GRAPHE

Les ressources hors Graphe sont généralement des ressources assistants utilisées comme données supplémentaires dans les Graphes ou pour aider à visualiser les résultats des Graphes. Les types suivants existent, chacun ayant une sous-page dans cette section des documents :
