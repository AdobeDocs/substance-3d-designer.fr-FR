## Description

Génère une primitive (polygone) au format Tracés.

Utilisez le nœud [Transformation 2D du tracé](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/path-2d-transform/path-2d-transform.md) pour positionner la primitive avec précision.

</td>

</table>

## Connecteurs de sortie

<b>Tracés</b> *Couleur*\
Contient une liste d’un chemin codé, décrivant une liste de segments codés.\
Il n’est pas destiné à être utilisé ou modifié directement. Recherchez Chemins pour trouver des nœuds compatibles.

## Paramètres

<b>Nombre de côtés</b> *Nombre entier*\
Conseil : entrez un nombre compris entre 100 et 1 000 pour générer un cercle.
