# Outils Path

Les outils de tracé sont un ensemble de nœuds permettant de générer et d’ajuster des tracés, ainsi que de les convertir en splines pour une diffusion ou une déformation complexe des images.

Les tracés sont une série de points reliés par des lignes droites.

Consultez ce tutoriel pour commencer :

>[!TIP]
>
> Nous vous recommandons d&#39;en savoir plus sur l&#39;[utilisation du chemin et des Outils spline](../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/working-with-path-and-spl/working-with-path-and-spline-tools.md) pour tirer le meilleur parti de l&#39;ensemble d&#39;outils.
> 
> Pour les utilisateurs avancés, la [spécification de format des chemins](../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/paths-format-spe/paths-format-specifications.md) explique comment les données des chemins sont codées dans des images couleur et fournit des conseils pour manipuler ces données directement.
