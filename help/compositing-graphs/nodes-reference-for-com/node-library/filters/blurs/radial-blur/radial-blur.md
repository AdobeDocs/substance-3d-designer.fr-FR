## Paramètres

|  |  |
|:---|:---|
| <b>Exemples</b> <i>1 - 128</i> | Définissez la qualité de l’effet de flou. |
| <b>Angle</b> <i>0.0 - 0.5</i> | Définissez la quantité de « rotation » de l’effet. |
| <b>Position centrale</b> | Définissez le point central de l’effet. |
