## Description

Effectue une opération mathématique de normalisation des vecteurs sur chaque pixel de l’image.

Cette option est utile lorsque de nombreuses fusions et modifications ont été apportées à la texture Normale et que vous souhaitez vous assurer que le résultat correct est exporté.
