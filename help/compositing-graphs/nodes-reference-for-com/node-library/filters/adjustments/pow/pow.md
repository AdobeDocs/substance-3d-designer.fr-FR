## Description

Alimente la saisie par un exposant spécifié. Similaire au réglage du milieu de [niveaux](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md)dans un package plus simple. Utile également lorsque vous voulez effectuer une opération de puissance mathématique exacte.

Important : assurez-vous d’utiliser la bonne version, selon que vous avez une entrée Couleur ou Niveaux de gris !
