## Description

Min Max trouve les valeurs les plus claires et les plus sombres d&#39;une entrée Niveaux de gris et les renvoie sous la forme [Valeurs](https://helpx.adobe.com/fr/substance-3d/unlisted/documentation/sddoc/values-in-substance-3d-graphs-180192235.html). Il s&#39;agit d&#39;une alternative manuelle plus granulaire pour les [niveaux automatiques](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/auto-levels/auto-levels.md), où vous exposez les entrées de valeur d&#39;un nœud [niveaux](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md) et y branchez les valeurs de Min Max.

Pour utiliser ce nœud avec un niveau, vous devez au moins savoir comment utiliser la liste déroulante [Exposer le paramètre](../../../../../../compositing-graphs/manage-parameters/exposing-a-parameter/exposing-a-parameter.md), ainsi que l&#39;[onglet Entrée de valeur](https://helpx.adobe.com/fr/substance-3d/unlisted/documentation/sddoc/values-in-substance-3d-graphs-180192235.html).

## Paramètres

*Aucun paramètre.*
