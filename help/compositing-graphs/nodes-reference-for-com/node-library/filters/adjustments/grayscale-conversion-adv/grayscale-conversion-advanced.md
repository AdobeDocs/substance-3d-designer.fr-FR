<a name="parameters"></a>

## Paramètres

|  |  |
|:---|:---|
| <b>Type de niveaux de gris</b> <i>Désaturation, Luminance, Moyenne, Max, Min</i> | La désaturation définit la valeur de saturation sur 0, la luminance utilise les épaisseurs de Luminance officielles, la moyenne est identique au noeud atomique et Max et Min utilisent respectivement la valeur la plus lumineuse pour chaque couche. |
