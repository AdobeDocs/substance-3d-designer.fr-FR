# Décalage de l’histogramme

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>Entrée :</b> Filtres > Réglages

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Description

Déplace complètement toute la plage de l’image, en la bouclant lorsque vous atteignez les limites de la plage.

[Cliquez ici pour visionner une vidéo de Substance Academy sur le décalage de l’histogramme.](https://youtu.be/p9wcmJBFyGA?t=492)

</td>
</tr>
</table>

<a name="parameters"></a>

## Paramètres

|  |  |
|:---|:---|
| <b>Position</b> <i>0.0 - 1.0</i> | Valeur de décalage de l’entrée. 1,0 correspond à une rotation complète et est égal à 0,0. |
