## Paramètres

|  |  |
|:---|:---|
| <b>Min. Plage</b> <i>-2.0 - 0.0</i> | Plage minimale pour commencer la mise en surbrillance. |
| <b>Plage Max</b> <i>1.0 - 3.0</i> | Plage maximale à sélectionner. |
