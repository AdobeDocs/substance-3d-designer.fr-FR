## Description

Outil de débogage pour vérifier les zones exactes avec Plage dynamique élevée. Les versions en couleurs et en niveaux de gris existent.

## Paramètres

* **Min. plage** : *-2.0 - 0.0* Plage minimale pour commencer la mise en surbrillance.
* **Plage max** : *1.0 - 3.0* Plage maximale à mettre en surbrillance jusqu&#39;à.
