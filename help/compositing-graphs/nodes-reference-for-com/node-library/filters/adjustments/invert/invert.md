## Description

Inverse les couleurs d’entrée.

Important : assurez-vous d’utiliser la version appropriée pour vos commentaires. Utilisez « Inverser » pour les entrées de couleur, « Inverser les niveaux de gris » pour les entrées de niveaux de gris.
