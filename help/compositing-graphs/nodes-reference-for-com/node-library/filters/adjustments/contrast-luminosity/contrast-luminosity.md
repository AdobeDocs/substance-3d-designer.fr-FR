## Description

Un réglage simple du contraste et de la luminosité.

## Paramètres

* **Contraste** : *-1,0 - 1,0*\
  Règle le contraste du résultat.
* **Luminosité** : *-1,0 - 1,0*\
  Règle la luminosité du résultat.
