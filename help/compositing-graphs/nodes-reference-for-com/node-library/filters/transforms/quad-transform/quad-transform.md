## Description

Nœud de transformation spécial qui permet la transformation d’une forme en quad par interaction avec ses points d’angle. Permet des transformations très spécifiques de manière pratique.

## Paramètres

* **p00** : point supérieur gauche.
* **p01** : point inférieur gauche
* **p10** : point supérieur droit.
* **p11** : point inférieur droit.
* **Abattage** :*Avant uniquement, Arrière uniquement, Avant sur arrière, Arrière sur avant* Définissez l&#39;abattage/le masquage de la forme lorsque les points se croisent.
* **Activer les limites** : *Faux/Vrai*
* **Couleur d&#39;arrière-plan** : *(valeur Niveaux de gris)*Couleur d&#39;arrière-plan unie si la mosaïque est désactivée.
* **Échantillonnage** : *Bilinéaire, Au Plus Proche* Définir la qualité d&#39;échantillonnage.
