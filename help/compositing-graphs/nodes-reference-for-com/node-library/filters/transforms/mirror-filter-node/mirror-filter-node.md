## Description

Permet de refléter l’image d’entrée sur un axe choisi, d’un côté choisi. C&#39;est un moyen très utile et rapide d&#39;obtenir des effets symétriques.

## Paramètres

* **Mode** : *Axe de miroir X, Axe de miroir Y, Miroir* *Coin* Choisissez de refléter le coin gauche-droit, le coin supérieur-inférieur ou les deux.
* **Décalage de l&#39;axe X** : *0.0 - 1.0* Utilisé uniquement lorsque l&#39;axe X est choisi, définissez un décalage.
* **Décalage de l&#39;axe Y** : *0.0 - 1.0* Utilisé uniquement lorsque l&#39;axe Y est choisi, définissez un décalage.
* **Inverser l&#39;axe X** :*Faux/Vrai*&#x200B;À utiliser uniquement lorsque l&#39;axe X est choisi, Inverser la direction.
* **Inverser l&#39;axe Y** :*Faux/Vrai* Cette option est utilisée uniquement lorsque l&#39;axe Y est choisi, Inverser la direction.
* **Type d&#39;angle** :*En haut à gauche, en haut à droite, en bas à gauche, en bas à droite* Utilisé uniquement lorsque le type d&#39;angle est choisi, définissez l&#39;angle à dupliquer.
