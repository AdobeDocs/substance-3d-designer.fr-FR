## Description

Permet de refléter l’image d’entrée sur un axe choisi, d’un côté choisi. C&#39;est un moyen très utile et rapide d&#39;obtenir des effets symétriques.

<a name="parameters"></a>

## Paramètres

|  |  |
|:---|:---|
| <b>Mode</b> <i>Axe de miroir X, Axe de miroir Y, Coin miroir</i> | Choisissez de créer une symétrie gauche-droite, haut-bas ou les deux. |
| <b>Décalage Axe X</b> <i>0.0 - 1.0</i> | Utilisé uniquement lorsque l’Axe X est choisi, définissez un décalage. |
| <b>Décalage Axe Y</b> <i>0.0 - 1.0</i> | Utilisé uniquement lorsque l’Axe Y est choisi, définissez un décalage. |
| <b>Inverser l&#39;Axe X</b> <i>Faux/Vrai</i> | Utilisé uniquement lorsque l’Axe X est choisi, Inverser la direction. |
| <b>Inverser l&#39;Axe Y</b> <i>Faux/Vrai</i> | Utilisé uniquement lorsque l’Axe Y est sélectionné, Inverser la direction. |
| <b>Type d&#39;angle</b> <i>En Haut À Gauche, En Haut À Droite, En Bas À Gauche, En Bas À Droite</i> | Utilisé uniquement lorsque le type d’angle est choisi, il définit l’angle à dupliquer en miroir. |
