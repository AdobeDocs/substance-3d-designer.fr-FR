# Outils HDRI

Les Outils HDRI sont des nœuds conçus pour manipuler et créer des images HDRI. Plus précisément, cela signifie que ces nœuds disposent de fonctionnalités pour travailler et générer des valeurs de Plage dynamique élevée correctes, ainsi que des nœuds qui tiennent compte du mappage de projection sphérique et le compensent.
