# vue 3D (bibliothèque)

La catégorie vue 3D contient uniquement des nœuds associés à des HDRI projetés sphériques, soit ceux utilisés dans la vue 3D de Substance 3D Designer, soit pour l’exportation vers d’autres applications telles que Substance 3D Painter.

Il existe deux sous-catégories :

* **Environnements HDRI** : aucune documentation n&#39;est disponible, car il s&#39;agit uniquement d&#39;images destinées à être affichées dans la vue 3D, sans paramètres supplémentaires.
* **Outils HDRI** : nœuds d’outils pour la création et la modification d’images HDRI sphériques. Introduit dans le DD 2019.2.
