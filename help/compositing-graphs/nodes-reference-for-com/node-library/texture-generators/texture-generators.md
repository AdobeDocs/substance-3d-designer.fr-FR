# Générateurs de textures

Les générateurs de textures sont des nœuds qui ne nécessitent aucune entrée : ils génèrent des images entièrement à partir de zéro. Vous pouvez considérer les « générateurs de textures » comme un autre terme pour les « procédures ».

Elles se répartissent en deux catégories :

* [Bruits](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/noises.md)\
  Les bruits sont les véritables graphiques procéduraux, les formes aléatoires et les pixels, comme les bruits bien connus de Perlin et de Clouds.
* [Motifs](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/patterns.md)\
  Les motifs sont principalement des formes qui semblent créées par l’homme, avec de nombreuses commandes supplémentaires pour les rendre aléatoires.
