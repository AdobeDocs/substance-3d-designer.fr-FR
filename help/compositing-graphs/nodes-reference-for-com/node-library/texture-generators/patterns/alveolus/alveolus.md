<a name="parameters"></a>

## Paramètres

|  |  |
|:---|:---|
| <b>Mosaïque</b> <i>1 - 16</i> | Définit le nombre de fois où le résultat doit se produire. |
| <b>Cellules en dégradé</b> <i>Faux/Vrai</i> | Passe aux contours nets pour créer des carreaux hexagonaux aux contours nets. |
| <b>Largeur de l&#39;interstice</b> <i>0.0 - 1.0</i> | Fonctionne uniquement lorsque l’option ci-dessus est définie sur « False ». Modifie la taille des interstices. |
| <b>Extension non carrée</b> <i>Faux/Vrai</i> | Permet la compensation de la courbure et de l’étirement avec des proportions non carrées. |
