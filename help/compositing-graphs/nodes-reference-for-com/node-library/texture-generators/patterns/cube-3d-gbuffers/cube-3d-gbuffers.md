## Description

Version avancée de [Cube 3D](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/cube-3d/cube-3d.md) qui génère également la position et les maps normal au lieu de la carte de hauteur uniquement.

## Paramètres

|  |  |
|:---|:---|
| <b>Décalage d&#39;orientation</b> | Permet une rotation X et Y du cube de type 3D. Peut également être effectué en manipulant le petit point dans l’aperçu 2D. |
| <b>Taille</b> <i>0.0 - 1.0</i> | Permet un redimensionnement non uniforme du cube. |
| <b>Échelle</b> <i>0.0 - 1.0</i> | Redimensionne uniformément le cube entier. |
| <b>Extension non carrée</b> <i>Faux/Vrai</i> | Active la compensation de la courbure et de la étire avec des proportions non carrées. |
