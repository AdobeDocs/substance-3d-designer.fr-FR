## Description

Génère un motif d’armure simple. Comporte des contrôles pour la randomisation. Au niveau du désordre max, cela peut même être utilisé comme bruit.

</td>
</tr>

<a name="parameters"></a>

## Paramètres

|  |  |
|:---|:---|
| <b>Répétition</b> <i>1 - 16</i> | Définit le nombre de fois où le résultat doit se produire. |
| <b>Désordre</b> <i>0.0 - 100.0</i> | Saute autour des mailles du tissage pour introduire de la variation. |
| <b>Rotation De 45 Degrés</b> <i>Faux/Vrai</i> | Fait pivoter selon un angle prédéfini. |
| <b>Extension non carrée</b> <i>Faux/Vrai</i> | Active la compensation de la courbure et de la étire avec des proportions non carrées. |
