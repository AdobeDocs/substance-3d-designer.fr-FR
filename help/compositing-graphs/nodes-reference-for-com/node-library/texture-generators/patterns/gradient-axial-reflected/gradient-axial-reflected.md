# Dégradé axial réfléchi

</td>

## Description

Comme l&#39;[axe de dégradé](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/gradient-axial/gradient-axial.md), crée un dégradé de niveaux de gris entre deux points personnalisés, où les dégradés commencent et se terminent en noir et culminent en blanc au centre de la transition. Gardez à l’esprit que les résultats ne sont pas toujours affichés en mosaïque.

</td>
</tr>
</table>

<a name="parameters"></a>

## Paramètres

|  |  |
|:---|:---|
| <b>Point 1</b> | Premier point de départ du dégradé (noir) |
| <b>Point 2</b> | Deuxième point pour terminer le dégradé à (blanc) |
| <b>Extension non carrée</b> <i>Faux/Vrai</i> | Activez la compensation de la courbure et de l’étirement avec des rapports non carrés. |
