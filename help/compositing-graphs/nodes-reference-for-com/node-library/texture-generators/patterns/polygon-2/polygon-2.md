## Description

Génère une forme polygonale en dégradé lisse avec des options de réglage. Voir [Polygone 1](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/polygon-1/polygon-1.md) pour une version plus avancée.

<a name="parameters"></a>

## Paramètres

|  |  |
|:---|:---|
| <b>Côtés</b> <i>3 - 32</i> | Quantité de côtés. |
| <b>Échelle</b> <i>0.0 - 1.0</i> | Définit l’échelle globale. |
| <b>Rotation</b> <i>0.0 - 1.0</i> | Fait pivoter la forme entière. |
| <b>Courbe</b> <i>-1.0 - 1.0</i> | Modifie la courbe de profil de dégradé. |
| <b>Dégradé</b> <i>0.0 - 1.0</i> | Règle le contraste du dégradé. |
| <b>Inverser le dégradé</b> <i>Faux/Vrai</i> | Inverse la direction du dégradé. |
| <b>Mise à l&#39;échelle automatique</b> <i>Faux/Vrai</i> | Se met à l’échelle pour s’adapter à la zone de travail avec les paramètres par défaut. |
| <b>Extension non carrée</b> <i>Faux/Vrai</i> | Permet la compensation de la courbure et de l’étirement avec des proportions non carrées. |
