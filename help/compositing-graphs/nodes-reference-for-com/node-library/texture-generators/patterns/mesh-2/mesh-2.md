## Description

Motif de maille simple avec des blocs de graisse. Peut être utilisé pour créer des cartes d’height et de détail.

## Paramètres

* **Mosaïque** : *1 - 16*\
  Définit le nombre de fois où le résultat doit se produire.
* **Rotation de 45 degrés** :*Faux/Vrai* Fait pivoter le résultat.
* **Extension non carrée** : *Faux/Vrai*\
  Permet la compensation de la courbure et de l’étirement avec des proportions non carrées.
