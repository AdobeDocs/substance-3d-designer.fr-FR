## Description

Modèle de maillage simple avec des blocs de graisse. Peut être utilisé pour créer des cartes d’height et de détail.

</td>

<a name="parameters"></a>

## Paramètres

|  |  |
|:---|:---|
| <b>Mosaïque</b> <i>1 - 16</i> | Définit le nombre de fois où le résultat doit se produire. |
| <b>Rotation De 45 Degrés</b> <i>Faux/Vrai</i> | Fait pivoter le résultat. |
| <b>Extension non carrée</b> <i>Faux/Vrai</i> | Permet la compensation de la courbure et de l’étirement avec des proportions non carrées. |
