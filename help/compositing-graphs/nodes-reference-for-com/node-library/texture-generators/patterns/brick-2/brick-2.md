## Description

Motif de brique simple, voir [Générateur de briques](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/brick-generator/brick-generator.md) ou [Tile Generator](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md) pour plus d&#39;options.

## Paramètres

* **Mosaïque** : *1 - 16*\
  Définit le nombre de fois où le résultat doit se produire.
* **Smoothness des contours** :*0.0 - 1.0* Mélange entre les contours nets et lisses.
* **Largeur de l&#39;interstice** : *0.0 - 1.0* définit l&#39;interstice (taille de l&#39;espace).
* **Extension non carrée** : *Faux/Vrai*\
  Permet la compensation de la courbure et de l’étirement avec des proportions non carrées.
