## Description

Cela génère un bruit ondulé de type fourrure.

## Paramètres

* **Échelle** : *1 - 8*\
  Définit l’échelle globale de l’effet.
* **Échelle des vagues** : *0.0 - 1.0*\
  Modifie l’échelle des vagues. Plus la valeur est élevée, moins il y a de répétitions.
* **Rotation des vagues** : *0.0 - 1.0*\
  Déforme davantage les vagues. Cette valeur doit probablement être maintenue basse, car les résultats peuvent être extrêmes.
* **Extension non carrée** : *Faux/Vrai*\
  Permet la compensation de la courbure et de l’étirement avec des proportions non carrées.
