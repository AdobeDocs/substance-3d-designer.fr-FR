## Description

Il s&#39;agit d&#39;une variante simple du [bruit gaussien](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/gaussian-noise/gaussian-noise.md), qui [se déforme](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/warp/warp.md) avec lui-même pour créer un effet de type liquide.

## Paramètres

* **Échelle** : *1 - 128*\
  Définit l’échelle globale de l’effet.
* **Trouble** : *0,0 - 1,0*\
  Déphasage du bruit pour introduire une faible variation
* **Intensité de déformation** : *0.0 - 1.0*\
  Définit l’intensité de l’effet de déformation.
* **Extension non carrée** : *Faux/Vrai*\
  Permet la compensation de la courbure et de l’étirement avec des proportions non carrées.
