## Description

Le nœud **Rasages Usure/salissures** dans [Substance 3D Designer](https://www.adobe.com/fr/products/substance3d-designer.html) génère une carte usure/salissures semblable aux rasages dispersés sur une surface.

<a name="parameters"></a>

## Paramètres

|  |  |
|:---|:---|
| <b>Balance</b> <i>Flottant</i> | Règle la balance entre les valeurs sombres et claires. |
| <b>Contraste</b> <i>Flottant</i> | Règle le contraste de l’image. |
| <b>Inverser</b> <i>Booléen</i> | Inverse la sortie de l&#39;image, à l&#39;aide d&#39;une opération `1-x`. |
| <b>Extension non carrée</b> <i>Booléen</i> | Active la compensation de la courbure et de la étire avec des proportions non carrées. |
| <b>Avancé</b> |  |
| <b>Quantité de défauts de rayure</b> <i>Flottant</i> | Quantité et *couverture* de l’effet de taches rayées utilisé pour générer des copeaux. |
| <b>Répétition des défauts de rayure</b> <i>Entier</i> | Niveau de répétition de l’effet de taches rayées utilisé pour générer les copeaux. |
| <b>Intensité du Dust</b> <i>Flottant</i> | Intensité de l’incrustation du dust sur la surface. |
| <b>Netteté</b> <i>Flottant</i> | Intensité de l’effet de netteté globale. |
