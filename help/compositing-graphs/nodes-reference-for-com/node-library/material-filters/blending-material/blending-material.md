# Fusion (Matériau)

La catégorie Fusion est l’une des catégories de matériaux multicanaux les plus importantes. Il contient des nœuds destinés à combiner, commuter et fusionner des matériaux constitués de plusieurs sorties simultanées.

Ces nœuds peuvent économiser d&#39;énormes quantités de travail, mais assurez-vous de bien comprendre les [modes de création de liens](../../../../../interface/the-graph-view/link-creation-modes/link-creation-modes.md) pour les utiliser correctement.

Les nœuds suivants sont bons pour commencer :

* [Fusion multi-Matériaux](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/multi-material-blend/multi-material-blend.md)
* [Fusion de réglage du matériau](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/material-adjustment-blend/material-adjustment-blend.md)
