# TSL

<td style="border: 0;" valign="top">

Règle la teinte, la saturation et la luminosité d’une image couleur.

Il s’agit d’un nœud simple et facile à utiliser, très utile lors de l’utilisation de données de couleur.

Si vous recherchez d&#39;autres façons de modifier les tons d&#39;une image, consultez les sections [Courbe](../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/curve/curve.md), [Niveaux](../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md) et [Contraste/Luminosité](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/contrast-luminosity/contrast-luminosity.md).

</td>

## Paramètres

|  |  |
| --- | --- |
| <b>Teinte</b> *Flottant* | Détermine la couleur de l’image d&#39;entrée.   Les valeurs inférieures à 0,5 modifient la teinte négativement, les valeurs supérieures à 0,5 la modifient positivement. |
| <b>Saturation</b> *Flottant* | Détermine la saturation de la couleur de l’image d&#39;entrée.   Les valeurs inférieures à 0,5 diminuent la saturation, les valeurs supérieures à 0,5 l’augmentent. |
| <b>Luminosité</b> *Flottant* | Détermine la luminosité des valeurs d’image d&#39;entrée. Les valeurs inférieures à 0,5 diminuent la Luminosité, les valeurs supérieures à 0,5 l’augmentent. |
