## A

|                                                                                        |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="alpha" data-preserve-html="true"></span>Canal Alpha</b> | Quatrième couche d’une image couleur, souvent utilisée pour décrire l’opacité. |
| <b><span id="ambient-occlusion" data-preserve-html="true"></span>Ambient occlusion</b> | L&#39;atténuation de la lumière ambiante sur les surfaces moins exposées et donc plus difficiles à atteindre. |
| <b><span id="anisotropy" data-preserve-html="true"></span>Anisotropie</b> | Propriété d&#39;être dépendant de la direction. Autrement dit, fournir un résultat différent lorsqu&#39;il est mesuré ou observé sur un axe différent.<br><br>L&#39;aspect des matériaux anisotropes varie en fonction de leur origine. Ils ne sont pas appliqués de manière uniforme dans toutes les directions. |
| <b><span id="aov" data-preserve-html="true"></span>AOV</b> | Variable de sortie arbitraire (AOV) est un terme utilisé dans le [rendu](#rendering) pour décrire les canaux de données supplémentaires qui peuvent être générés à partir d&#39;un rendu, tels que la profondeur, les normales ou les données personnalisées. |
| <b><span id="api" data-preserve-html="true"></span>API</b> | Une interface de programmation d&#39;application (API) est un ensemble de fonctions et de procédures qui permet aux utilisateurs d&#39;accéder aux fonctions et aux procédures d&#39;une autre application de programme.<br><br>Une API fournit une couche contrôlée et sécurisée entre l&#39;utilisateur et un programme. Il peut également utiliser un autre langage de programmation pour rendre ce programme plus facile à interagir et plus largement accessible.<br><br>Designer propose une [API Python](../scripting/scripting.md) qui fournit un accès facile à un large éventail de ses fonctionnalités pour la manipulation des données, la création d&#39;outils personnalisés et l&#39;accélération des workflows. |
| <b><span id="atomic-node" data-preserve-html="true"></span>Noeud atomique</b> | Les éléments de base des graphes. Tous les [instanciers](#instance-node) peuvent être décomposés en graphes de noeuds atomiques.<br>Chaque type de graphe a son propre ensemble de noeuds atomiques. |

## B

|                                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="baking" data-preserve-html="true"></span>Baking</b> | Processus consistant à calculer des informations à partir d&#39;un modèle 3D et à stocker les résultats dans une [texture](#texture). Les données sont placées dans la texture de données en fonction des [UV](#uv) du modèle. |
| <b><span id="base-color" data-preserve-html="true"></span>Base color</b> (Albédo) | Canal d&#39;un matériau [](#material) défini à l&#39;aide du modèle de Métallique rugosité PBR [ombrage](#shader).<br>La Base color spécifie la couleur d&#39;une surface sans aucune information d&#39;éclairage.<br><br>À ne pas confondre avec [Diffuse](#diffuse). |
| <b><span id="base-parameter" data-preserve-html="true"></span>Paramètre de base</b> | Paramètre commun à tous les nœuds d&#39;un graphe de Substance de données qui calculent un [bitmap](#bitmap).<br><br>Il s&#39;agit notamment des aspects fondamentaux de l&#39;image bitmap, tels que sa résolution ([taille de sortie](#output-size)) et son [nombre de bits par pixel](#bit-depth) ([format de sortie](#output-format)), ou la façon dont l&#39;image bitmap est calculée, par exemple en mode [répétition](#tiling).<br><br>Les paramètres de base sont souvent [hérités](#inheritance) d&#39;autres nœuds en amont ou du graphe hébergeant le nœud. |
| <b><span id="bilinear-filtering" data-preserve-html="true"></span>filtrage Bilinéaire</b> | Processus d&#39;interpolation utilisé en imagerie informatique lorsqu&#39;un [échantillon de texture](#texture-sampling) n&#39;est pas effectué exactement au centre d&#39;un pixel.<br><br>Par exemple, cela peut se produire lorsqu&#39;une image est agrandie. |
| <b><span id="bit-depth" data-preserve-html="true"></span>Nombre de bits par pixel</b> | Nombre de bits utilisés pour stocker la valeur d’un pixel dans une texture. Des nombres de bits par pixel plus élevés permettent de coder davantage de valeurs, ce qui produit des dégradés plus lisses.<br><br>Différents nombres de bits par pixel sont disponibles selon le type de la valeur : - Les valeurs d’Entier peuvent être codées à l’aide de 8 bits (0 à 255) ou de 16 bits (0 à 65 535). - Les Valeurs de point flottant peuvent être codées en utilisant 16 bits (+32767,9999 à -32768,0 ) ou 32 bits (-3,4E+38 à +3,4E+38)<br><br>Les images à faible plage dynamique utilisent des valeurs d’entier pour coder les étapes de 0 à 1. Les images de plage dynamique élevée utilisent des valeurs de point flottant pour coder des valeurs numériques brutes.<br><br>Dans les graphes de Substance, le nombre de bits par pixel est contrôlé par le paramètre [Format de sortie](#output-format). |
| <b><span id="bitmap" data-preserve-html="true"></span>Bitmap</b> | Une image numérique. Deux types d’images sont les plus courants :<ul data-preserve-html="true"> <li data-preserve-html="true">les Images en niveaux de gris n&#39;ont qu&#39;un seul canal: luminance (L);</li> <li data-preserve-html="true">Les images couleur comportent trois couches : rouge, vert et bleu (RGB). Un quatrième paramètre peut être présent : [alpha](#alpha) (A), souvent utilisé pour l&#39;opacité. Les images couleur dans Designer sont toujours RVBA.</li> </ul>  Les bitmaps peuvent être considérés comme des grilles de valeurs. Chaque cellule de cette grille est un pixel, ce qui est abrégé en « élément d’image ». Un pixel stocke une valeur par couche. Le type de cette valeur dépend du [nombre de bits par pixel](#bit-depth) du bitmap. |

## C

|                                                                                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="cache" data-preserve-html="true"></span>Cache</b> (Mémoire) | Une collecte de données - Par ex. [paramètres de base](#base-parameter) du nœud et images de sortie - stockés en mémoire pour être réutilisés.<br><br>Le cache accélère considérablement les calculs de graphe en laissant la [Substance Engine](#substance-engine) recalculer uniquement les parties d&#39;un graphe qui ont été modifiées. Lorsque vous ajustez les connexions et les paramètres des nœuds, tous les nœuds qui les précèdent ne sont pas affectés par ces modifications. Il n&#39;est donc pas nécessaire de les [évaluer](#evaluation) à nouveau pour mettre à jour le graphe. Leur cache est utilisé à la place.<br><br>Le cache peut avoir une empreinte mémoire importante lors de l&#39;utilisation de résolutions et de débits de bits élevés dans des graphes volumineux. |
| <b><span id="channel-packing" data-preserve-html="true"></span>packing de canal</b> | Technique d’optimisation consistant à compresser des images séparées dans les couches du RGB (A) d’une seule image couleur.<br><br>Par exemple, une texture RMA est une carte de [rugosité](#roughness) (R), une carte de métallisme (M) et une carte d&#39;[ambient occlusion](#ambient-occlusion) (A), le tout regroupé dans une seule texture de couleurs.<br><br>Une autre technique courante consiste à effectuer un packing d&#39;une texture en niveaux de gris dans la couche bleue d&#39;une [map normal](#normal-map), car la couche bleue, c&#39;est-à-dire le composant &#39;Up&#39; du vecteur normal, peut être recalculée lors de l&#39;exécution.<br><br>Le nœud [Fusion RVBA](../compositing-graphs/nodes-reference-for-com/node-library/filters/channels/rgba-merge/rgba-merge.md) est utile pour mettre en œuvre cette technique. |
| <b><span id="color-space" data-preserve-html="true"></span>Espace colorimétrique</b> | Définition de la représentation d’une plage de couleurs.<br>Le codage et le décodage numériques d&#39;une couleur spécifique nécessitent une telle définition pour donner un sens aux nombres utilisés.<br><br>Un fichier image stocke les valeurs de couleur à l&#39;aide d&#39;un espace colorimétrique spécifié, afin que ces couleurs puissent être fidèlement reproduites sur un écran qui prend en charge cet espace colorimétrique. Un écran dispose de capacités de reproduction des couleurs spécifiques qui lui permettent de prendre en charge entièrement ou partiellement un espace colorimétrique donné.<br><br>Données brutes - Par ex. une [map normal](#normal-map) est toujours codée et décodée dans un espace colorimétrique linéaire, car ces couleurs ne sont pas destinées à être visualisées et aucune transformation ne doit être appliquée à ces données.<br><br>sRGB est un espace colorimétrique largement pris en charge. Les autres espaces colorimétriques populaires sont Adobe RGB, Rec. 2100 et ProPhoto RGB. |
| <b><span id="cooking" data-preserve-html="true"></span>Cuisine</b> (<span id="compilation" data-preserve-html="true"></span>Compilation) | Processus consistant à translater des données dans un autre langage afin qu’elles puissent être exécutées rapidement et efficacement.<br>Le calcul du résultat d&#39;un graphe de Substance nécessite sa compilation préalable. La compilation fait partie du processus d&#39;[évaluation](#evaluation) du graphe.<br><br>Cette compilation est effectuée sur un graphe aplati, ce qui signifie que tous les [instanciers](#instance-node) sont &#39;remplacés&#39; par leurs graphes source afin qu&#39;il reste un graphe plus grand et que ce graphe soit compilé.<br><br>Un graphe compilé n&#39;est pas modifiable. Les paramètres exposés restent disponibles s&#39;ils sont [dynamiques](#dynamic-parameter), tandis que les paramètres [statiques](#static-parameter) sont verrouillés et masqués. |
| <b><span id="culling"></span>Abattage</b> | Technique d&#39;optimisation du [rendu](#rendering) [scènes 3D](#three-d-scene) qui supprime la géométrie des calculs d&#39;un rendu lorsqu&#39;elle n&#39;est pas visible.<br><br>Cela peut inclure des objets ou des polygones en dehors du tronc de caméra (*abattage du tronc de cône*), orientés à l&#39;opposé de la caméra (*backface culling*) ou complètement masqués par d&#39;autres objets opaques (*abattage de l&#39;occlusion*). |

## B

|                                                                                        |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="dependency" data-preserve-html="true"></span>Dépendance</b> | Un fichier A qui est utilisé par un autre fichier B de telle manière que le fichier B ne fonctionne pas comme prévu lorsque le fichier A est manquant.<br><br>Une dépendance d&#39;un [package](#package) peut être un autre package, car il fait référence à un graphe qu&#39;il contient, à un fichier image, à une police, etc.<br><br>Un package stocke le chemin d&#39;accès à sa dépendance et un avertissement est généré si la dépendance est introuvable dans ce chemin. Les dépendances manquantes peuvent également entraîner [des instanciers de fantôme](#ghost-instance-node) dans un graphe. |
| <b><span id="diffuse" data-preserve-html="true"></span>Diffuse</b> | Canal d&#39;un modèle [matériau](#material) défini à l&#39;aide du modèle [ombrage](#shader) de Brillance PBR Specular. L’option Diffuse spécifie la couleur d’une surface lorsqu’elle est éclairée.<br><br>À ne pas confondre avec [Base color (Albédo)](#base-color). |
| <b><span id="directx" data-preserve-html="true"></span>DirectX</b> | Collection d’API pour la gestion de contenu multimédia. Son API 3D, Direct3D, est largement utilisée dans le développement de jeux vidéo et d’autres industries 3D.<br><br>Direct3D place l’origine d’une texture, c’est-à-dire sa coordonnée (0, 0), en *haut à gauche* (Y-bas), tandis que l’API [OpenGL](#opengl) la place en *bas à gauche* (Y-haut).<br><br>Cela signifie qu’une [map normal](#normal-map) de DirectX a un *canal vert inversé* par rapport à OpenGL. En effet, le canal vert héberge la coordonnée Y des vecteurs normaux. |
| <b><span id="displacement" data-preserve-html="true"></span>Displacement</b> | Processus consistant à déplacer les [vertex](#vertex) d&#39;un modèle 3D, souvent selon leur [normale](#normal).<br><br>Le Displacement est souvent utilisé en association avec la [tessellation](#tessellation) et les [maps normal](#normal-map) pour modéliser des détails plus fins sur une surface. |
| <b><span id="dynamic-parameter" data-preserve-html="true"></span>Paramètre dynamique</b> | Paramètre dont la valeur peut changer. En d&#39;autres termes, tout paramètre dont la valeur n&#39;est pas constante est dynamique.<br><br><br>Cela inclut les paramètres exposés, tous les paramètres affectés par un paramètre exposé et toute valeur de paramètre affectée par l&#39;[échantillonnage dans une texture de données](#texture-sampling).<br><br>Contrairement aux [paramètres statiques](#static-parameter), la valeur des paramètres dynamiques peut être ajustée à la volée après la compilation du graphe en un [Fichier sbsar](#sbsar-file). |

|                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|--------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="evaluation" data-preserve-html="true"></span>Évaluation</b> | Processus de résolution de la propagation des données et des paramètres dans le graphe. L&#39;évaluation vérifie la validité d&#39;un graphe et de ses connexions, applique [héritage](#inheritance) et [cuisine](#cooking) le graphe.<br><br>En Vue du graphe de compte, une connexion est représentée par une ligne pointillée lorsqu&#39;elle n&#39;est pas évaluée.<br>L&#39;évaluation transforme la connexion en lignes pleines.<br><br><br>Chaque fois qu&#39;un paramètre est ajusté dans un graphe, le nœud hébergeant ce paramètre et tous les nœuds en aval sont [invalidés](#invalidation) et doivent être réévalués avant d&#39;être [rendus](#rendering). |

## V

|                                                                                            |                                                                                                                                                                                                                                                                                                                                                                                        |
|--------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="ghost-instance-node" data-preserve-html="true"></span>instancier du Fantôme</b> | Un [instancier](#instance-node) faisant référence à un [sous-graphe](#subgraph) introuvable, c&#39;est-à-dire une [dépendance](#dependency) manquante, est chargé en tant qu&#39;instancier de fantôme.Les instanciers de Fantôme <br><br>sont restaurés à leur état attendu en résolvant la dépendance manquante et en rechargeant le [package](#package). |
| <b><span id="glossiness" data-preserve-html="true"></span>Brillance</b> | Canal d&#39;un modèle [matériau](#material) défini à l&#39;aide du modèle [ombrage](#shader) de Brillance PBR Specular. La brillance spécifie la rugosité d&#39;une surface, c&#39;est-à-dire les variations microscopiques de l&#39;height, également appelées *microfacettes*.<br><br>Une brillance élevée donne un aspect lisse, tandis qu&#39;une brillance faible donne un aspect rugueux et mat.<br><br>C&#39;est l&#39;inverse de la [Rugosité](#roughness). |

## H

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="histogram" data-preserve-html="true"></span>Histogramme (image)</b> | Dans le contexte d&#39;une image, un histogramme représente la population des valeurs dans une plage donnée, souvent [0, 1].<br><br>Cette population est visualisée à l&#39;aide de barres verticales où une valeur plus présente dans l&#39;image entraîne une barre plus élevée pour cette valeur.<br>Les barres sont réparties horizontalement entre des valeurs basses (foncées) et des valeurs élevées (claires).<br><br>Les histogrammes des images couleur chevauchent généralement les histogrammes de chacune de leurs couches, en général R, V, B. |

## I

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="inheritance" data-preserve-html="true"></span>Héritage</b> | Dans le cadre des graphes de Substance, héritage décrit la propriété des nœuds acquérant des valeurs de paramètres à partir de leurs nœuds en amont, ou de leur graphe parent.<br><br>Les paramètres hérités incluent la [résolution](#resolution) ([taille de sortie](#output-size)), la [profondeur de bits](#bit-depth) ([format de sortie](#output-format)) et le mode [répétition](#tiling).<br><br>En savoir plus sur l&#39;héritage dans cette [page dédiée](../compositing-graphs/inheritance-compositing/inheritance-in-substance-compositing-graphs.md). |
| <b><span id="instance-node" data-preserve-html="true"></span>Instancier</b> | Un instancier représente un graphe A dans un autre graphe B. Dans ce cas, le graphe A peut être appelé [sous-graphe](#subgraph) du graphe B. Toute modification apportée au graphe A est propagée à tous les instanciers qui la représentent.<br><br>L&#39;instancier applique son propre ensemble de valeurs pour les paramètres d&#39;entrée du graphe A dans le graphe B. En ce sens, le graphe B peut héberger plusieurs instanciers qui font tous référence au graphe A, mais chacun transmet des valeurs ou des textures différentes en tant qu&#39;entrées dans le graphe A.<br><br>Tous les nœuds de la bibliothèque Designer qui ne sont pas des [noeuds atomiques](#atomic-node) sont des instanciers. |
| <b><span id="invalidation" data-preserve-html="true"></span>Invalidation</b> | Processus déclarant que le résultat d&#39;un nœud est obsolète.<br><br>Lorsqu&#39;un paramètre est ajusté, le nœud hébergeant ce paramètre et tous les nœuds en aval sont invalidés. Ils doivent donc être [évalués](#evaluation) et [rendus](#rendering). |

## M

|                                                                      |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|----------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="material" data-preserve-html="true"></span>Matériau</b> | Ensemble des propriétés et des comportements de la matière dans l&#39;espace, qui comprend les surfaces et les volumes.<br>L’apparence d’une entité dans l’espace 3D est définie par son matériau.<br><br>Les Matériaux peuvent être définis de différentes manières et toutes les définitions ne prennent pas en charge toutes les propriétés telles que la réfraction, l&#39;anisotropie ou l&#39;éclat. Un [shader](#shader) est une implémentation particulière d&#39;une définition de matériau.<br><br><b>Important :</b> le terme « matériau » est un *terme générique* utilisé pour désigner diverses choses, notamment :<ul data-preserve-html="true"> <li data-preserve-html="true">Le [shader](#shader) utilisé pour calculer l&#39;apparence d&#39;une surface ou d&#39;un volume ;</li> <li data-preserve-html="true">L&#39;ensemble de [textures](#texture) fournies à un shader ;</li> <li data-preserve-html="true">Un ID de Matériau, qui est un attribut d’une primitive 3D utilisée pour distinguer les parties qui utilisent différents matériaux.</li> </ul> |
| <b><span id="mesh" data-preserve-html="true"></span>Maillage</b> | Objet 3D composé de [vertex](#vertex) reliés par des arêtes pour former des polygones, tels que des triangles, qui sont à leur tour assemblés en surfaces. Ces surfaces peuvent être ouvertes ou fermées.<br><br>L&#39;apparence de ces surfaces est définie par le [matériau](#material) qui leur est attribué.<br>Le niveau de détail d&#39;un maillage dépend également fortement de son [polycount](#polycount). |
| <b><span id="metadata" data-preserve-html="true"></span>Métadonnées</b> | Données qui fournissent des informations sur le fichier lui-même, son environnement ou tout élément lié aux données du fichier.<br><br>Les métadonnées courantes incluent l’auteur du fichier, les dates de création et de modification, le copyright et les illustrations de couverture.<br><br>Dans Designer, le contenu d&#39;un [package](#package) peut également contenir des métadonnées. Par exemple, un graphe de Substance générant un matériau de fabric peut contenir des métadonnées relatives aux propriétés physiques du fabric. |
| <b><span id="mipmap" data-preserve-html="true"></span>Mipmap</b> | Version plus petite d&#39;une [texture](#texture), souvent calculée automatiquement.<br><br>Une texture peut avoir une pyramide de versions plus petites d&#39;elle-même, qui sont interchangeables au moment de l&#39;exécution afin que la taille la plus appropriée soit utilisée pour une qualité et des performances optimales.<br><br>Par exemple, une texture avec des détails à haute fréquence affichés à une taille plus petite produira probablement des artefacts de *moiré*. En outre, une texture plus importante implique probablement plus d&#39;[échantillons de texture](#texture-sampling).<br><br>Le terme « mipmap » provient de la technique de mappage MIP, où MIP signifie le latin « *multum in parvo* », ce qui signifie « beaucoup de choses dans un petit endroit ». |

## N

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|--------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="node" data-preserve-html="true"></span>Nœud</b> | Objet dans un graphe qui exécute des calculs et génère un ou plusieurs résultats.<br><br>Le résultat est contrôlé à l&#39;aide de paramètres d&#39;entrée. Ces paramètres peuvent être répertoriés en tant que contrôles dans le dock Propriétés ou en tant que connecteurs d&#39;entrée sur le nœud lui-même.<br><br>Il existe deux catégories principales de nœuds : [noeuds atomiques](#atomic-node) et [instanciers](#instance-node). |
| <b><span id="noise" data-preserve-html="true"></span>Bruit</b> | Image non figurative représentant une distribution aléatoire ou pseudo-aléatoire de formes et de couleurs. Les bruits sont souvent utilisés pour ajouter de la variation aux surfaces ou aux déformations.<br><br>La bibliothèque de nœuds de Designer comprend une grande collection de générateurs de bruits, tels que les [taches BnW](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/bnw-spots-2/bnw-spots-2.md), les [nuages](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/clouds-2/clouds-2.md), le [bruit Perlin](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/perlin-noise/perlin-noise.md) ou le [Voronoi](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/voronoi/voronoi.md). |
